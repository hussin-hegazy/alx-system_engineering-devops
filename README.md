# SSH Script

This repository contains a Bash script to connect to a remote server using SSH with a private key.

## Script

- `0-use_a_private_key`: Connects to the server `18.206.208.230` using the private key located at `~/.ssh/school`.

## Requirements

- Ensure the private key `~/.ssh/school` exists and has the correct permissions.
- The script must be executable (`chmod +x 0-use_a_private_key`).
